Doctor scans the workspace for health problems and surfaces each as a finding card (statuses: `open`, `dismissed`, `fixed`), grouped under a run. Kicking off a scan is asynchronous and self-throttling: `POST /run` returns 202 when it actually queues a new run, 200 when it hands back a recent run instead, and 409 if one is already in flight — so poll `/status` or the run's cards rather than assuming fresh results. You can only request an agent fix (`/findings/:id/fix`) on a card that is still `open`, and only one fix per card at a time (409 otherwise). Use `import` when you already have raw doctor output to ingest instead of running a live scan.
