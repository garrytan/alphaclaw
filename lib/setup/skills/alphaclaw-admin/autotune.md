Resource autotune sizes AlphaClaw's settings to this container — gateway memory, agent concurrency, body limits, database caches, advisory backup budget — re-deriving at boot and on resizes. `GET /api/autotune` returns the ledger: detected capacity and each knob's value + status (applied / pending_restart / skipped / clamped / manual) with reasons. `PUT /api/autotune/settings` pins per-key overrides (`null` clears; machine-clamped). Live usage: `GET /api/watchdog/resources`.
