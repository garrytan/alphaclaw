Resource autotune sizes AlphaClaw's resource-dependent settings to this container — gateway memory, agent concurrency, request size limits, database caches, and an advisory backup budget — re-deriving at boot and on resizes. `GET /api/autotune` returns the ledger: detected capacity, each knob's derived value, and applied / pending-restart / skipped status with reasons. `PUT /api/autotune/settings` pins overrides per key (`{"overrides":{"gatewayHeapMb":6144}}`; `null` clears; clamped to the machine). Live usage is `GET /api/watchdog/resources`. On OOM or sluggish reports: check live usage, suggest an override, then `POST /api/autotune/reapply`.
