Resource autotune sizes AlphaClaw's resource-dependent settings to this container — gateway memory, agent concurrency, request size limits, database caches, and an advisory backup storage budget — re-deriving them at boot and when the container is resized. `GET /api/autotune` returns the full ledger: what was detected, what each knob derived to, and whether it is applied, pending a restart, or skipped (with the reason). An override pins one knob: `PUT /api/autotune/settings` with `{"overrides":{"gatewayHeapMb":6144}}` merges per key, and an explicit `null` clears a key back to the derived value — never resend keys you don't mean to change. Overrides are clamped to what this machine can actually hold, so a too-large value is applied reduced, not verbatim. Capacity here is static; live usage (memory, CPU, disk, processes, event loop) comes from `GET /api/watchdog/resources`. When an admin reports OOM crashes or sluggishness, check live usage first, then suggest a specific override and run `POST /api/autotune/reapply` to apply it.
