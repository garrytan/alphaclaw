Manages the Codex CLI OAuth connection that grants AlphaClaw access to OpenAI models. Check `status` to see whether a profile is connected and when its token expires, disconnect to revoke it, and use `exchange` to finish a login by hand. Gotcha: the connect flow is interactive and browser-first — the authorize step opens a login page a human completes, then you paste the full redirect URL into `exchange` to complete the PKCE code exchange; there is no headless connect. You can, however, complete an already-started exchange and disconnect entirely from here.
