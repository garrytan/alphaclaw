Two launch paths live behind the sidebar's Open Claude Code button: the cloud **routine fire** (`POST /api/claude-code/session` fires a saved claude.ai routine — a session in Anthropic's cloud) and the **local rescue session** (`local/*` — a Claude Code instance running on this box inside a detached tmux session, reached through a revocable rescue link). The button prefers the local session once its one-time login is done and falls back to the routine otherwise.

Every mutating operation here is humans-only: starting, steering, or logging into a remote-controlled `acceptEdits` shell on this box is privilege escalation — the same reasoning as the original routine-fire denial. `status` is safe for you but redacted: `local.sessionUrl`, `local.sessionId` (it reconstructs the claude.ai URL canonically), `local.login.oauthUrl`, the error tail, and warnings are stripped for the agent actor (tails can carry arbitrary box content beyond what `.env` redaction knows about). The stripped `sessionUrl` is a hard boundary: it is the rescue capability link (`/rescue/<token>`), an unauthenticated redirect — the token is the credential for a live remote-controlled shell on this box until the session stops. Treat any rescue link you encounter as a live credential: never repeat, store, or relay it. Use status to answer "is the launcher healthy"; send the operator to the Watchdog page's rescue-session card for everything else.

Disclosures to relay when asked: a rescue session can read content on this box, including untrusted log content (prompt injection through logs is a real risk), and transmits selected content to Anthropic as part of operating Claude Code. Unattended spawns (autostart and incident auto-spawn) always clamp to `acceptEdits`; `bypassPermissions` only ever reaches a session through an interactive click whose confirmation named the mode.

The state-by-state operator runbook and the `CLAUDE_CODE_LOCAL_*` env-key reference live in the README under "Open Claude Code Launcher → Local rescue session" — point operators there.
