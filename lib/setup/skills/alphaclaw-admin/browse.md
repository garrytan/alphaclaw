The workspace file browser: read, write, create, move, delete, and download files under the workspace root, plus git-aware operations (per-file diff, restore, and a commit-and-push `git-sync`). Everything is confined to the workspace root — paths are resolved server-side, so traversal outside the tree is rejected. Locked and protected paths (AlphaClaw-managed files, secret-bearing directories like `.alphaclaw/**`, credentials, and auth profiles) are enforced server-side and return 403 on write/create/move/delete — including moving or deleting an ANCESTOR folder that contains one, and the workspace root itself is never a mutation target (400) — so don't try to route around them. The manifest also DENIES (403 `denied`, no confirm) any read or mutation naming `openclaw.json`, `alphaclaw.json`, `devices/`, `.alphaclaw/`, credential stores, or an agent's `auth-profiles.json` — `../` spellings and `.bak` rotations included; use the dedicated ops (`env.*`, `models.*`, `team.*`) or hand it to the operator. Delete is recursive and force-enabled with no confirmation, so treat it as irreversible unless the file is git-tracked and recoverable via restore.
