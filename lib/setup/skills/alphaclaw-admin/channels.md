Manages the messaging accounts (Telegram, Discord, Slack, WhatsApp) the agent connects through — adding, removing, updating tokens, and running provider login. Adding or removing an account is restart-tier: prefer the async jobs endpoint, which returns `202` with an `operationId` and `streamUrl` you poll for phase progress rather than blocking on the synchronous create. Updating a token also flags a restart as required (`restartRequired: true`), so it won't take effect until the process cycles. Tokens always read back masked — you cannot recover a stored secret through the API, only overwrite it.
