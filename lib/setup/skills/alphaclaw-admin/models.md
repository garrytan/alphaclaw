Controls which AI model the agent runs on — the default/primary model, its fallbacks, per-model settings, and thinking-effort options — plus the auth profiles that store provider credentials (each an `api_key`, `token`, or `oauth`, keyed by provider). Setting the model or writing model config is restart-tier: apply it, then tell the user a gateway restart is needed before it takes effect. Auth-profile secrets go via `--data-stdin`, never on the command line; API-key profiles stay synced with the matching provider env var, so a key set here also shows up under `env` (and vice versa).
