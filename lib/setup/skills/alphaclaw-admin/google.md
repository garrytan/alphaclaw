Manages the Google Workspace OAuth accounts and per-client credentials (client ID/secret, scopes) that back gog. Use these endpoints to register credentials, list/check accounts, and disconnect — but you cannot fully connect an account from here: completing the OAuth consent flow requires a human to open the auth URL in a browser, so hand off rather than trying to finish it yourself. Note that `clientSecret` reads back masked, so a saved secret will not round-trip through a GET. For day-to-day gog CLI usage (reading mail, calendar, drive, etc.), see the gog-cli skill instead.
