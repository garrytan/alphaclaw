Controls OpenClaw's scheduled jobs: list them and their scheduler status, trigger an immediate run, enable/disable, and edit a job's prompt or routing (session target, wake mode, and delivery mode/channel/target). These routes operate on existing jobs only — there's no create or delete here, so a job the operator hasn't defined elsewhere won't appear in the list. Gotcha: `POST /api/cron/jobs/{id}/run` is a live run, not a dry run — it executes the prompt and delivers the result to the job's configured channel just like a scheduled firing, so read the routing before you trigger one. Run history, per-job and bulk usage, and trends are all read-only, so pull them freely to see what a job has been doing. Delivery routing points at the messaging accounts administered under channels.
