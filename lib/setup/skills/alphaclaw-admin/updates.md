Read `GET /api/openclaw/channel` before changing a build. Selecting stable/beta/dev only changes the catalog preference (`restartRequired: false`). Applying or rolling back changes the running build and restarts the gateway, ending your session; treat these as dangerous final actions and warn the user first. A `202` with `operationId` means work started: poll the durable run ledger for its outcome after restart. Failures carry `code` and `hint`; relay both. `GET /api/openclaw/backups` lists producer, age, verified/partial status and reuse eligibility so the operator can assess recovery. Never send `allowBackupReuse`, `confirmNoBackup` or `confirmNoBackupToken`: their presence is denied for agents (403), and consent issuance is also human-only. On `backup_failed` or `backup_required_for_migration`, relay the hint and direct the operator to the failed run in Upgrade. An eligible human waiver removes backup protection only; compatibility, ownership and gateway holds still apply.
