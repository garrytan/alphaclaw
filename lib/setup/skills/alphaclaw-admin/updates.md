Read `GET /api/openclaw/channel` before changing a build. Channel selection changes catalog preference only (`restartRequired: false`). Applying or rolling back restarts the gateway and ends your session; warn the user before these dangerous final actions. A `202` with `operationId` starts work: poll the durable run ledger after restart. Relay failure `code` and `hint`. `GET /api/openclaw/backups` lists provenance, age, coverage and reuse eligibility. A `migration-minimal` archive protects migration state, omits workspace and cannot be reused for a later update. Never send `allowBackupReuse`, `confirmNoBackup` or `confirmNoBackupToken`: agents receive 403, and consent issuance is human-only. On `backup_failed` or `backup_required_for_migration`, direct the operator to the failed run in Upgrade. A human waiver removes backup protection only; compatibility, ownership and gateway holds still apply.
