OpenClaw's version is pinned by the AlphaClaw release; there is no in-app version switch. `updates.backup` runs OpenClaw's own `openclaw backup create --verify` in the background (the gateway keeps running); poll `updates.backup.status` until `running` is false and report `last.archivePath` or `last.error`. A second start while one runs is `409 backup_in_progress`. Restoring an archive is an operator task.
