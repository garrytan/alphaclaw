Manages agent definitions, their channel bindings, and which one is the default. Each agent owns a workspace, and a binding is what routes a given channel account to that agent — set the default with `POST /api/agents/{id}/default`. Gotcha: deleting an agent tears down its bindings, and passing `keepWorkspace=false` on the DELETE also removes its workspace directory (the default keeps it); prefer removing individual bindings first when you only mean to re-route. Channel accounts (the credentials a binding points at) are administered from the same routes here, so create the account before you try to bind it.
