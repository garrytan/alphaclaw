Manages agent definitions, their channel bindings, and which one is the default. Each agent owns a workspace, and a binding is what routes a given channel account to that agent — set the default with `POST /api/agents/{id}/default`. Gotcha: deleting an agent tears down its bindings, and passing `keepWorkspace=false` on the DELETE also removes its workspace directory (the default keeps it); prefer removing individual bindings first when you only mean to re-route. Channel accounts (the `channel`/`accountId` a binding points at) are administered under channels (`/api/channels/accounts`), and adding one there already binds it to the `agentId` you pass — so create the account there first; the bindings routes here don't check that the account exists, and are for re-routing or narrowing (peer, guild, team) an account that is already configured.
