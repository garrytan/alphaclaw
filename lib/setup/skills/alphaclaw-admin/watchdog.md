The watchdog supervises the AlphaClaw gateway process: read its health/status, recent events, log tail, and live resource usage — memory, CPU, disk, processes, and event loop lag — via `GET /api/watchdog/resources`, tune supervision settings, and trigger a repair when it's wedged. Machine capacity and the settings tuned from it live in the autotune domain. Note that `POST /api/watchdog/repair` relaunches the gateway, so channels drop briefly and any in-flight work is interrupted — reach for it only when status shows the gateway is actually down or stuck. The `terminal/*` endpoints are operator-only and will be denied for you, so don't route interactive shell work through here.
