Editable env vars and provider credentials (API keys, model config, custom keys). Reads are safe. `PATCH /api/env` sets one key (`{"key":"K","value":"v"}`) or deletes it (`{"key":"K","delete":true}`). PUT replaces the whole editable set: an omitted key is deleted. Reserved keys are skipped by PUT (`skipped`) and refused by PATCH; channel tokens are preserved. Send secrets with `--data-stdin`. A restart is flagged only when the gateway's launch env changes; otherwise `note` says none is needed (e.g. `ALPHACLAW_GIT_SYNC`). `ALPHACLAW_GIT_WRITER_COMMAND` is the operator's sanctioned commit-and-push command for the workspace repository: change it only when an admin asks; your next session sees it. A save returns `staleProcesses` (processes still on an old value until they restart); `GET /api/env/stale-processes` asks any time.
