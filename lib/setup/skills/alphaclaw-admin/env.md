Manages the editable environment variables and provider credentials backing the agent — API keys, model config, and any custom keys. Reads are safe, but PUT is a full replacement of the editable set: send every key you want to keep, because any currently-set key you omit is deleted. Reserved/system keys are rejected outright and managed channel tokens are preserved server-side, so you cannot clobber them here. Pass secret values through `--data-stdin` rather than the command line. Saving changed values may flag a restart as required before they take effect.
