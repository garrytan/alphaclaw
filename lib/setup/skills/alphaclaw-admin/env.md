Editable env vars and provider credentials (API keys, model config, custom keys). Reads are safe. `PATCH /api/env` sets one key (`{"key":"K","value":"v"}`) or deletes it (`{"key":"K","delete":true}`). PUT replaces the whole editable set: an omitted key is deleted. Reserved keys are skipped by PUT (`skipped`) and refused by PATCH; channel tokens are preserved. To get a secret from a person, use the secret drop (`references/secrets.md`), never a chat message; `PATCH` is for values you already hold that are not secrets, or an admin's explicit instruction. A restart is flagged only when the gateway's launch env changes; otherwise `note` says where each changed key is usable (AlphaClaw and scripts that read .env at once; the gateway after its next start when OpenClaw loads its .env, or never). `ALPHACLAW_GIT_WRITER_COMMAND` is the operator's sanctioned commit-and-push command for the workspace repository: change it only when an admin asks; your next session sees it. A save returns `staleProcesses` (processes still on an old value until they restart); `GET /api/env/stale-processes` asks any time.
