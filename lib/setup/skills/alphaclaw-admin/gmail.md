Controls Gmail push notifications via Cloud Pub/Sub: the OAuth client config plus per-account watch lifecycle (start, stop, renew, status). Each watch is scoped to an `accountId`, so start/stop/renew calls all require one — status omits it to list every account. The gotcha: Gmail watches expire and stop delivering unless renewed periodically, and `renew` defaults to `force: true`. Note that the actual push endpoint (`/gmail-pubsub`) is token-authenticated and outside this admin surface — these operations only configure and monitor the watch, they do not receive the notifications.
