## Pages

| Page     | URL                         | What it helps with |
| -------- | --------------------------- | ------------------ |
| Home     | `{{SETUP_UI_URL}}#home`     | Status and next steps — gateway, watchdog, incidents in the last 7 days and 30-day spend at a glance, what needs the owner (pending device approvals, OpenClaw data upgrade, Drift Doctor reminder, prompt-hardening problems, pin drift, workspace sync off), the finish-setting-up checklist, the next scheduled jobs, agents and channels summaries, and This box (versions and update, OpenClaw dashboard launch, hardening state, Back up now, repo auto-sync schedule) |
| Channels | `{{SETUP_UI_URL}}#channels` | Where people reach your agents — add, edit and delete channel accounts (Telegram/Discord/Slack/WhatsApp/Signal and others), WhatsApp QR linking, chat pairing approvals, device approvals |
| Groups   | `{{SETUP_UI_URL}}#groups`   | Telegram groups your agent is in, sorted by rule (waiting for you, custom, approved, trusted people, silent, blocked) — change a group's rule with a preview of the openclaw.json change, Test this group to see who the agent would answer and why, and the people blocked in every group |
| Integrations | `{{SETUP_UI_URL}}#integrations` | Services and tools this box connects to — Google Workspace accounts, feature health (memory embeddings, audio transcription), OpenAI-compatible API and Agent Administration toggles, links to Webhooks and Nodes |
| Chat     | `{{SETUP_UI_URL}}#chat`     | Web chat with your agents — one conversation per session, relay conversations included, with run status and history |
| Schedules | `{{SETUP_UI_URL}}#schedules` | Scheduled jobs — the job list beside the selected job (on a phone the list, then the job with Back), scheduler status, enable/disable, run now, prompt and delivery-routing edits, rolling calendar, run history, trends and per-run usage |
| Usage    | `{{SETUP_UI_URL}}#usage`    | Token and cost reporting — 30-day spend, turns, tokens and the most used model, the daily chart, a by-agent table and sessions with per-session detail |
| Doctor   | `{{SETUP_UI_URL}}#doctor`   | Drift Doctor workspace health scans — a one-line result of the last run with Run Doctor, open findings (fixed and dismissed folded away), deterministic environment and model-drift checks, context-injection budget meter, scheduled scans, fixes dispatched to the agent |
| Health   | `{{SETUP_UI_URL}}#health`   | Gateway supervision — a one-line health headline with Restart gateway, Repair and View logs, gateway and watchdog status, memory, disk and CPU meters, live status narrative, incidents and optional AI overseer, auto-repair, notification channel and admin targets, memory-leak detection and resource-autotune settings, event log, log tail, terminal, Claude Code rescue session |
| Relay    | `{{SETUP_UI_URL}}#relay`    | Agent Relay (self-hosted agent-to-agent messaging) — health, the agents on the relay, relay messages waiting on the owner or failed, the logged message history (bodies shown to signed-in people only) |
